# SAFU_ProProgramming

НАЧАЛО
    Ввод a, b

    Ввод x

    ПОКА x < a ИЛИ x > b
        Вывод "Повторите ввод"
        Ввод x
    КОНЕЦ ПОКА

    Вывод x
КОНЕЦ

НАЧАЛО
    Ввод eps

    S := 0
    k := 0

    ПОКА ИСТИНА
        term := (-1)^k / 2^k
        S_old := S
        S := S + term

        ЕСЛИ |S - S_old| < eps ТО
            ВЫХОД ИЗ ЦИКЛА
        КОНЕЦ ЕСЛИ

        k := k + 1
    КОНЕЦ ПОКА

    Вывод S
КОНЕЦ
